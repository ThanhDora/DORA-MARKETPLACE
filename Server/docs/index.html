01

Overview

Mini Marketplace API cung cấp RESTful interface để tương tác với nền tảng thương mại điện tử. Hỗ trợ bán tài khoản game, key phần mềm, và file số.

REST Architecture

API tuân thủ REST conventions với HTTP methods chuẩn: GET, POST, PUT, PATCH, DELETE.

JWT Authentication

Access token (15 phút) trong Authorization header. Refresh token (7 ngày) trong HttpOnly cookie.

Rate Limiting

authLimiter: 10 req/15 phút. strictLimiter: 5 req/15 phút. Default: 100 req/15 phút.

Email Notifications

Tự động gửi email thông báo: login alert, welcome, verify email, password reset.

Standard Response Format

{
  "success": true,
  "message": "Thành công",
  "data": { ... }
}
{
  "success": false,
  "message": "Error description",
  "errors": [...]
}
{
  "pagination": {
    "page": 1,
    "limit": 12,
    "total": 156,
    "totalPages": 13
  }
}
02

Authentication

API sử dụng JWT tokens để xác thực người dùng. Access token có thời hạn 15 phút.

Bearer Token

Thêm access token vào header Authorization cho tất cả protected endpoints:

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

User Roles

USER Người dùng thông thường
SELLER Có thể đăng và quản lý sản phẩm
ADMIN Quản trị viên - duyệt sản phẩm, quản lý users

Token Flow

1
Register / Login

Nhận accessToken và refreshToken (cookie)

→
2
Gửi request với Bearer token

Authorization: Bearer <accessToken>

→
3
Token hết hạn (401)

Gọi POST /auth/refresh để lấy token mới

Errors & Status Codes

Mã lỗi chuẩn và cách xử lý từng loại error.

2xx

Success

  • 200 — OK
  • 201 — Created
  • 204 — No Content
4xx

Client Errors

  • 400 — Bad Request
  • 401 — Unauthorized
  • 403 — Forbidden
  • 404 — Not Found
  • 429 — Rate Limited
5xx

Server Errors

  • 500 — Internal Server Error
  • 502 — Bad Gateway
  • 503 — Service Unavailable
